Read these results honestly

  • Real Chandrayaan-2 runs have no independent check points, so RMSE there is transform self-consistency on the inliers, not ground-truth error.
  • Synthetic (SYN) sources come from the same renderer CHITRA uses, so they are an upper bound for Render-and-Match.
  • "Sub-pixel on OHRC↔NAC" is a target that these runs support. Literature numbers (SIFT IIRS→WAC ≈73 m, a preprint; CNSFM 72.3 % polar) are cited baselines, not ours.
